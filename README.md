### 🌟 Full-Stack & Arquitetura (Destaques)

* 🧠 **DUA Inteligente**: Editor institucional inteligente (Next.js, Supabase, IA) para criação de Planos Educacionais Individualizados (PEI), focado na inclusão de alunos neurodivergentes.
* 🛒 **Zero Zen Imports**: E-commerce streetwear completo estruturado em monorepo (Next.js + NestJS + Prisma), com controle de estoque dinâmico.
* 📬 **SysEmail**: SPA interativa para gestão e triagem geográfica de e-mails em tempo real utilizando TypeScript e Firebase Firestore.
